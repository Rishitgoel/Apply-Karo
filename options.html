Learned answers

When you fill something in by hand, the label and your answer are remembered. The next form that asks the same question gets the same answer, for free, without touching the model.

Custom fields

Extra facts that don't fit the standard profile — gender, salary expectation, notice period, years of experience. These outrank the rule engine, so they are the place to pin down an answer for good.

Common ones worth setting

Settings

Behaviour, appearance and your data.

Behaviour
Fill automatically
Fill as soon as a page is recognised as an application. Rule matches only — the AI pass never fires without you pressing Fill.
Highlight what was filled
Green outline for a rule match, amber for a guess worth checking.
Attach my resume
Uploads the resume from the Resume tab into a form's file box automatically. Boxes asking for a photo, a portfolio or a cover letter are left alone.
Skip sensitive questions
Leaves EEO, gender, race, veteran and disability questions alone on the automatic pass.
Show the on-page panel
The small launcher in the corner of application pages. The keyboard shortcut keeps working without it.
Track applications
Log each page you fill so the Applications tab can act as a tracker.
Count on the toolbar icon
Shows how many fields were filled on the current tab.
Sites switched off
Apply karo ignores these completely. Subdomains are covered too.
Backup

A JSON file with your profile, learned answers, settings and application log. The resume PDF is not included — it would multiply the file size for something already on your disk.

Privacy
Everything above is stored on this computer only. There is no account and no server — nothing is uploaded, and nothing is tracked. The one exception is the AI features, which send what you see described on the page below straight to the provider you picked, on your own API key, and only when you press a button.
